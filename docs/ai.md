# Artificial Intelligence

A curated index of AI tools, models, chatbots, and infrastructure — free, open source, or just genuinely useful. No fluff.

:::info Trust Rating Emojis

    **"💎"** indicates recommended and trusted source.
    **"🏆"** indicates the best pick in the author(s) opinion.

All tools listed here have been reviewed. Always use official sources linked below.
:::

---

## 💬 Chatbots & Assistants

General-purpose AI chat interfaces you can use right now, in the browser or via app.

- **🏆 [ChatGPT](https://chatgpt.com/)** — OpenAI's flagship model. GPT-4o is available free. Best all-rounder for writing, coding, reasoning, and general use.

- **🏆 [Claude](https://claude.ai/)** — Anthropic's assistant. Excellent at long documents, nuanced writing, and following complex instructions. Free tier available.

- **💎 [Gemini](https://gemini.google.com/)** — Google's assistant. Strong at multimodal tasks (images + text), deep Google integration, free tier available.

- **💎 [Mistral Le Chat](https://chat.mistral.ai/)** — Fast, free, and surprisingly capable. From the European AI lab Mistral. Good for everyday tasks.

- **💎 [Perplexity](https://www.perplexity.ai/)** — AI-powered search engine. Answers questions with cited web sources. Great for research and fact-checking.

- **🔗 [You.com](https://you.com/)** — AI assistant with real-time web search built in. Free to use.

- **🔗 [Phind](https://www.phind.com/)** — Developer-focused AI search. Particularly good for coding questions, with cited sources.

## 🧠 Open Source Models

Models you can download and run yourself — privately, offline, no API key needed.

- **🏆 [Llama 3](https://llama.meta.com/)** *(Meta)* — One of the best open-weight models available. Runs well locally. Multiple sizes from 8B to 405B.

- **🏆 [Mistral / Mixtral](https://mistral.ai/)** — High quality, efficient, open-weight models. Mistral 7B punches well above its size class.

- **💎 [Qwen 2.5](https://qwen.readthedocs.io/)** *(Alibaba)* — Strong multilingual model with excellent coding and reasoning. Available in many sizes.

- **💎 [Gemma 3](https://ai.google.dev/gemma)** *(Google)* — Lightweight open models optimised for efficiency. Great for lower-end hardware.

- **💎 [Phi-4](https://azure.microsoft.com/en-us/products/phi)** *(Microsoft)* — Small but punchy. Remarkable performance from a tiny model. Ideal for constrained environments.

- **🔗 [DeepSeek R2](https://www.deepseek.com/)** — Strong reasoning model from China. Open weights, competitive with top closed models on benchmarks.

- **🔗 [Falcon](https://falconllm.tii.ae/)** — Open-source models from the UAE's TII. Various sizes available.

## 🖥️ Run Models Locally

Software for running AI models on your own machine.

- **🏆 [Ollama](https://ollama.com/)** — The easiest way to run open source models locally. One-line install, simple CLI and API. Supports Llama, Mistral, Gemma, Qwen, and dozens more.

- **💎 [LM Studio](https://lmstudio.ai/)** — GUI application for downloading and running local models. Beginner-friendly, works on Windows, Mac, and Linux. Built-in chat interface.

- **💎 [Jan](https://jan.ai/)** — Open source, privacy-first local AI app. Clean UI, supports multiple backends. Good alternative to LM Studio.

- **🔗 [GPT4All](https://www.nomic.ai/gpt4all)** — Simple desktop app for local AI chat. Lightweight and easy to set up.

- **🔗 [llama.cpp](https://github.com/ggerganov/llama.cpp)** — The engine under the hood of many local AI tools. Raw CLI, maximum control, runs on CPU or GPU.

## 🎨 Image Generation

AI image generators — cloud and local.

- **🏆 [Stable Diffusion](https://stability.ai/)** — The open source image generation model. Runs locally, fully private, unlimited generations. The foundation of most open image AI.

- **💎 [ComfyUI](https://github.com/comfyanonymous/ComfyUI)** — Node-based interface for Stable Diffusion. Highly flexible, used by power users. Steep learning curve but very powerful.

- **💎 [Automatic1111](https://github.com/AUTOMATIC1111/stable-diffusion-webui)** — The most popular Stable Diffusion web UI. Feature-rich, massive community, tons of extensions.

- **💎 [Midjourney](https://www.midjourney.com/)** — Paid, closed-source, but produces consistently beautiful results. Runs through Discord. No free tier currently.

- **🔗 [DALL·E 3](https://openai.com/dall-e-3)** — OpenAI's image model. Integrated into ChatGPT Plus. Good prompt following, photorealistic results.

- **🔗 [Adobe Firefly](https://firefly.adobe.com/)** — Adobe's AI generator. Trained on licensed content. Safe for commercial use. Free tier with limited credits.

- **🔗 [Ideogram](https://ideogram.ai/)** — Particularly good at generating images with legible text. Free tier available.

## 🔊 Audio & Voice

AI tools for speech, music, and sound.

- **🏆 [Whisper](https://github.com/openai/whisper)** *(OpenAI)* — Open source speech-to-text. Highly accurate across many languages. Runs locally.

- **💎 [ElevenLabs](https://elevenlabs.io/)** — Realistic AI voice synthesis. Voice cloning, text-to-speech, multiple languages. Free tier available.

- **💎 [Suno](https://suno.com/)** — Generate full songs with vocals and instruments from a text prompt. Free tier available.

- **🔗 [Udio](https://www.udio.com/)** — Competitor to Suno. High quality AI music generation. Free tier available.

- **🔗 [Coqui TTS](https://github.com/coqui-ai/TTS)** — Open source text-to-speech. Many voices and languages. Fully local.

## 🛠️ Developer Tools

AI tools built for coding and development.

- **🏆 [GitHub Copilot](https://github.com/features/copilot)** — AI pair programmer integrated into VS Code and JetBrains. Excellent code completion and generation. Free for students and open source maintainers.

- **💎 [Cursor](https://www.cursor.com/)** — AI-first code editor (fork of VS Code). Context-aware edits across your whole codebase. Free tier available.

- **💎 [Continue](https://continue.dev/)** — Open source AI coding assistant. Works with local models via Ollama or cloud APIs. VS Code and JetBrains plugin.

- **💎 [Aider](https://aider.chat/)** — AI pair programmer in the terminal. Works with your git repo. Open source, supports many models.

- **🔗 [Codeium](https://codeium.com/)** — Free AI code completion. Works in most editors. Good Copilot alternative with a generous free tier.

- **🔗 [Tabnine](https://www.tabnine.com/)** — AI code completion with a local model option for privacy. Long-standing tool.

## 🗃️ Aggregators & Model Hubs

Places to browse, compare, and download AI models.

- **🏆 [Hugging Face](https://huggingface.co/)** — The GitHub of AI. Hosts hundreds of thousands of models, datasets, and demo apps. Essential resource.

- **💎 [Civitai](https://civitai.com/)** — Community hub for Stable Diffusion models, LoRAs, and embeddings. Huge library of fine-tuned image models.

- **🔗 [OpenRouter](https://openrouter.ai/)** — Single API to access dozens of models (OpenAI, Anthropic, Mistral, open source). Pay-per-token, very convenient for developers.

- **🔗 [Together AI](https://www.together.ai/)** — Fast inference for open source models. Good pricing, developer-focused.

## 📚 Learning & Research

Resources for understanding AI rather than just using it.

- **🔗 [Papers With Code](https://paperswithcode.com/)** — AI research papers with linked implementations. Great for following the cutting edge.

- **🔗 [Andrej Karpathy's YouTube](https://www.youtube.com/@AndrejKarpathy)** — The best free AI education on the internet. Deep, clear explanations from a former Tesla/OpenAI researcher.

- **🔗 [Fast.ai](https://www.fast.ai/)** — Free practical deep learning courses. Hands-on, code-first approach.

- **🔗 [LLM Leaderboard](https://huggingface.co/spaces/lmsys/chatbot-arena-leaderboard)** — Community-driven benchmark where humans compare AI models. Useful for picking models.
