##  Chatbots & Assistants

AI chat interfaces

- **🏆 [Claude](https://claude.ai/)** - Anthropic's AI assistant. Free tier is pretty good value.

- **🏆 [Gemini](https://gemini.google.com/)** - Google's AI assistant. Very strong with a good free tier as well.

- **💎 [Mistral Le Chat](https://chat.mistral.ai/)** - Fast and free LLM from Le Mistral

- **💎 [ChatGPT](https://chatgpt.com/)** - OpenAI's flagship model. GPT-4o is available free.

- **💎 [Perplexity](https://www.perplexity.ai/)** - AI-powered search engine which provides links to sources for transparency

- **💎 [You.com](https://you.com/)** - Free to use with lots of AI LLMs available.

## Open Source Models

Models you can download and run yourself offline with no API keys needed.

- **🏆 [Llama 3](https://llama.meta.com/)** - One of the best open-weight models available. Runs well locally. Multiple sizes from 8B to 405B.

- **🏆 [Mistral / Mixtral](https://mistral.ai/)** - High quality, efficient open-weights models. Mistral 7B is great.

- **💎 [Qwen 2.5](https://qwen.readthedocs.io/)** - Strong model and good for non native speakers.

- **💎 [Gemma 3](https://ai.google.dev/gemma)** - Lightweight models that run well on low end devices

- **💎 [Phi-4](https://azure.microsoft.com/en-us/products/phi)** - S

- **🔗 [DeepSeek R2](https://www.deepseek.com/)** - It might steal your data but its really good

- **🔗 [Falcon](https://falconllm.tii.ae/)** -

## Developer Tools

AI tools for coding.

- **🏆 [GitHub Copilot](https://github.com/features/copilot)** - Frre but its pretty limited

- **💎 [Cursor](https://www.cursor.com/)** - Free tier available, and can edit across your whole codebase.

- **💎 [Continue](https://continue.dev/)** - Open source AI coding assistant.

- **💎 [Aider](https://aider.chat/)** - Open source AI that runs in terminal

- **🔗 [Codeium](https://codeium.com/)** - Good free tier

- **🔗 [Tabnine](https://www.tabnine.com/)** - Local model option

- **🔗 [Fast.ai](https://www.fast.ai/)** - Free practical deep learning courses. Hands-on, code-first approach.

- **🔗 [LLM Leaderboard](https://huggingface.co/spaces/lmsys/chatbot-arena-leaderboard)** - Benchmark for comparing models. Useful for selecting the right model for your purpose
