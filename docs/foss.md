# FOSS

**Free and Open Source Software** - software anyone can view, modify, and distribute. The pick of the bunch.

:::info Trust Rating Emojis

    **"💎"** indicates recommended and trusted software.
    **"🏆"** indicates the best pick in the author(s) opinion.

All software listed here has been reviewed. Always download from the official sources linked below.
:::

## Browsers

- **🏆 [Firefox](https://www.mozilla.org/firefox/)** - This is an amazing privacy-respecting browser for general use. It is _quite_ lightweight and is a default browser alternative to using Chrome and the Google series. 

- **🏆 [Tor Browser](https://www.torproject.org/)** - This is the **GOLD STANDARD** when being called to being a privacy conserving browser as it is _THE_ privacy browser. 

    All data that is generated on Tor is routed through multiple servers at a level that makes your local so unambiguous, it becomes infeasible to pinpoint a location on your IP.

- **💎 [Brave](https://brave.com/)** - This is a good privacy choice compared to using traditional chromium, and it comes with a bunch of other privacy-preserving tools aswell.

- **🔗 [Ungoogled Chromium](https://github.com/ungoogled-software/ungoogled-chromium)** - This is modern Chromium (not Chrome) without the tracking or "google" that is usually included with Chrome and other Google related products.

    It is also very lightweight (as it is just a bundled version of the Chromium protocol.)


## Operating Systems

Linux. Just Linux.

>*Why only Linux?*

No other platform _truly_ does it better

Linux juggles with handling file management, [sockets and networking](/internet-tools#networking), [server hosting and management](/internet-tools#hosting), user management and many more features that make it a feature-proof OS while also being JAM PACKED with privacy, compatibility and customisation and levels that far supercede its competitors like **Windows** and **MacOS**...

(_and it's free_)

... but here are some actually useful **[Linux Distros](https://en.wikipedia.org/wiki/List_of_Linux_distributions)**.

- **🏆 [Ubuntu](https://ubuntu.org)** - This is an amazing choice (and the first choice for many) when looking into Linux distros. It works well, supports pretty much anything, runs pretty much anything, and has built in packages such as `apt install`. It also comes with a default GUI and is good for server support.

    >Lots of Linux Distros actually just base themselves off of Ubuntu while adding extra features.

- **🏆 [Arch](https://archlinux.org/)** - (I use arch btw). It's a good "hacker-person" distro which is lightweight and pretty useful for terminal use on Personal Computers.

- **💎 [Fedora](https://fedoraproject.org/)** - battle tested kernel that operates CPU speed at substancially faster than most other distros. Also comes with a polished daily driver.

- **💎 [Kali](https://www.kali.org/)** - The greatest distro for penetration testing, _ethical hacking_ (👀👀), and cyber-security. You'll see a lot of people working in cybersec using this distro. It comes with tools like [Metasploit](/hacking-tools#Metasploit) and [Wireshark](/hacking-tools#Wireshark) OFF the HOOK.

- **💎 [Tails](https://tails.net/)** - The most portable operating system. It entirely avoids surveillance via third parties injecting into malware by instead keeping the entire OS stored in memory. This means that the entire OS can be wiped just by restarting your computer, removing all traces.
