## Internet Encryption

Many modern day services run over HTTPS which allow data to be transferred from Person A (you) to a website without malicious people being able to intercept the network and gain access to the data being shared (think logins and [PII](/privacy.html#:~:text=PII%20(Personally%20Identifiable%20Information))).
